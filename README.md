# Airbnb Listing Clone - Romantic Jacuzzi 1BHK Candolim

Pixel-perfect clone of Airbnb listing page built for PlayPower Labs assessment.

Reference: https://airbnb-clone-umber-two.vercel.app

## Tech Stack
- Next.js 14 App Router
- Tailwind CSS
- TypeScript

## Features Implemented
- 5-image photo grid with Show all photos button
- Photo Tour full-screen modal with room categories
- Lightbox with prev/next, counter, Esc to close, focus trap, body scroll lock
- Sticky header with tabs Photos, Amenities, Reviews, Location
- Sticky booking card with price breakdown ₹28,499 for 5 nights
- Calendar with 2 months, Reviews 4.95 Guest Favourite, Map, Host section
- More stays nearby horizontal scroll
- Fully responsive and keyboard accessible
- npm run build passes

## Run Locally
npm install
npm run dev
Open http://localhost:3000

## Build
npm run build
